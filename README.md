# 🎲 Python Board Game

Un joc de societate interactiv pentru 2 jucători, dezvoltat în Python (Tkinter) folosind Programarea Orientată pe Obiecte (OOP). 

## 🌟 Funcționalități
* **Multiplayer local:** 2 jucători cu pioni distincți pe tabla de joc.
* **Mecanică de zar:** Aruncare randomizată a zarului pentru avansarea pe traseu.
* **Provocări dinamice:** Fiecare căsuță pe care aterizezi declanșează o provocare unică.
* **Arhitectură OOP:** Cod modular structurat pe clase (ex: `Player`, `BoardGameApp`).
